PLATFORM OVERVIEW

═══════════════════════════════════════════

NDH operates as a DIGITAL BUREAU (not a marketplace). Clients submit tasks to the company, NDH assigns the tasks to vetted in-house talents, reviews the work for quality, and delivers it back to clients. Talents and clients never communicate directly. NDH also runs an academy (NDH Academy) that trains digital skills like a real online university (similar to Iconic Open University), with departments, HODs, instructors, semesters, exams, and certifications.

KEY FEATURES & SYSTEMS

═══════════════════════════════════════════



1. GEO-PRICING SYSTEM

   - Auto-detect client country by IP

   - Display currency based on location: NGN (Nigeria), USD (US/International), GBP (UK), EUR (Europe), CAD (Canada), AED (UAE)

   - Same service shows different rate based on region (configurable in admin)

   - Profit margin: Talent earns 50–60%, NDH keeps 40–50% (fair and balanced)



2. TIER-BASED TASK SUBMISSION

   - Basic / Professional / Premium tier options

   - Budget range slider

   - "Open to negotiation" toggle

   - PM sends custom quote → client approves → pays



3. ESCROW PAYMENT SYSTEM

   - Client pays NDH upfront

   - Funds held by platform

   - Released after delivery confirmation

   - Integrate Paystack + Flutterwave (Nigeria) + Stripe + PayPal (International)



4. WEEKLY PAYROLL SYSTEM

   - Auto-calculate talent earnings per week

   - Finance Admin approves

   - Bulk payment to talent bank accounts

   - Payment receipts auto-generated

   - Email notifications sent automatically (from billing@ndh.com.ng)



5. TALENT TIER SYSTEM

   - 5 tiers: Junior → Intermediate → Senior → Lead → Elite

   - Auto-calculated promotion based on performance metrics

   - Visible progress bar in talent dashboard



6. QA SYSTEM

   - PMs review every submitted task

   - Approve or send back with revision notes

   - Quality scoring per talent



7. CERTIFICATE GENERATION

   - Auto-generate PDF certificates with student name, course, grade, unique ID, QR code

   - Public verification page (ndh.com.ng/verify/CERT-XXXX)

   - Signed digitally by Academy Director and Founder



8. NOTIFICATION SYSTEM

   - In-app, email (using NDH emails), and SMS notifications

   - Push notifications for PWA

   - Email senders:

     * support@ndh.com.ng → support messages

     * billing@ndh.com.ng → payment receipts/invoices

     * academy@ndh.com.ng → academy notifications

     * noreply@ndh.com.ng → automated alerts



9. MESSAGING SYSTEM

   - Real-time chat between clients ↔ PMs

   - Talents ↔ PMs

   - Students ↔ Instructors

   - File sharing supported



10. ACADEMIC CALENDAR & LMS

    - Semester structure

    - Lecture schedules (live + pre-recorded)

    - Assignment deadlines

    - Mid-semester tests

    - Final exams or projects

    - Auto-unlock next module after completion
